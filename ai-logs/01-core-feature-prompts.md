# Core Feature Prompts

## AR Exhibit Scanning

Prompt: Help implement a mobile-first museum exhibit scanning page using MindAR. The scan result should unlock exhibit observations, clue keywords, and update the current game state.

## NPC Dialogue

Prompt: Help design an NPC dialogue system where different role, exhibit, and NPC combinations unlock different narrative clues. Invalid combinations should still give useful exploration hints.

## Multiple Endings

Prompt: Help implement a story reconstruction and multiple-ending system based on collected clues. Each ending should have a story title, description, score, grade, and required clue set.

## Leaderboard And Profile

Prompt: Help connect the ending submission flow to Supabase and display global and role-based leaderboards on a profile page.

## Bilingual Interface

Prompt: Keep the Chinese and English language system, but make English the default language for first-time users while preserving the Chinese mode content.
